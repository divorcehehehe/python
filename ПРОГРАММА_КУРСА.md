# Программа курса «Python для начинающих»

Факультатив для студентов технического вуза: 7 пар по 90 минут. Инструменты: Python 3.12+,
PyCharm Community, Windows. Курс завершается курсовым проектом: консольная игра в ООП-стиле.

**Как устроена каждая пара.** Титул с целью урока, короткое повторение прошлой темы, новые
понятия с живыми примерами кода и выводом, два-три мини-упражнения «Попробуй сам» на 3–5 минут
прямо по ходу, разбор частых ошибок, итоги и 5–6 задач в конце пары. Ответы на мини-упражнения
и подсказки лектору лежат в заметках докладчика. Решения задач для преподавателя лежат
в папке `solutions` каждого урока, примеры для показа вживую в папке `demo`.

### Урок 1. Старт: числа, строки, условия

Файл: `lesson_1/1_Старт.pptx`. Цель: написать программу, которая читает данные, считает и печатает ответ, ветвясь по условию.

Темы: Зачем Python; Установка; Первая программа в PyCharm; print и переменные; Числа: int и float; Почему 0.1 + 0.2 не равно 0.3; Строки; input(): читаем ввод; f-строки; bool и сравнения; and, or, not; if, elif, else; Пример целиком: оценка по баллам.

Задачи:

1. ★ **Индекс массы тела.** Прочитайте рост в метрах и вес в килограммах, каждое число в своей строке. ИМТ = вес / рост². Выведите ИМТ с одним знаком и категорию по неокруглённому значению: меньше 18.5 недостаток, меньше 25 норма, меньше 30 избыток, иначе ожирение.
2. ★ **Сумма цифр.** Прочитайте трёхзначное число и выведите сумму его цифр. Используйте `//` и `%`.
3. ★★ **Секунды в часы.** Прочитайте количество секунд и выведите его в формате ч:мм:сс.
4. ★★ **Квадратное уравнение.** Прочитайте a, b, c (каждое в своей строке, a не равно 0) и решите уравнение ax² + bx + c = 0. Если дискриминант отрицательный, выведите «нет корней»; если он равен нулю (с точностью 1e-9), выведите «x = …»; иначе «x1 = …, x2 = …», где x1 считается с плюсом перед √D. Два знака после точки.
5. ★★★ **Проверка результата.** Прочитайте a, b, c (c не равно 0) и ожидаемый результат, каждое число в своей строке. Вычислите a + 8b² / (4c), выведите его с тремя знаками и `True`, если разница с ожидаемым меньше 0.001, иначе `False`. Подумайте, почему сравнивать через `==` плохая идея. *(по желанию)*

Файл: `lesson_2/2_Циклы_и_строки.pptx`. Цель: повторять действия циклом и обрабатывать текст.

Задачи:

1. ★ **Половинки.** Две строки, каждая на своей строке. Выведите первую половину первой и вторую половину второй, при нечётной длине половина округляется вниз.
2. ★ **Палиндром.** Прочитайте строку и выведите через f-строку, палиндром она или нет. Регистр не учитывается.
3. ★★ **Число плюс наоборот.** Прочитайте целое число и сложите его с числом, записанным задом наперёд.
4. ★★ **Простое число.** Прочитайте число и определите, простое ли оно. Делители ищите до корня. Числа меньше 2 не простые.
5. ★★ **Шифр Цезаря.** Строка из строчных латинских букв, на второй строке сдвиг. Сдвигайте буквы вперёд, после `z` снова `a`.

2. ★★ **Топ-3 слов.** Выведите три самых частых слова строки без учёта регистра, по одному в строке в формате «слово число». При равной частоте раньше идёт то слово, которое встретилось первым. Разных слов может оказаться меньше трёх.
3. ★★ **Сортировка пузырьком.** Числа задаются одной строкой. Отсортируйте их пузырьком, без `sort` и `sorted`, и выведите через пробел.
4. ★★ **Серия чётных.** Числа задаются одной строкой. Выведите самую длинную серию подряд идущих чётных чисел, иначе слово «нет».
5. ★★ **Матрица.** Прочитайте число n, затем n строк по n чисел. Выведите транспонированную матрицу и сумму главной диагонали.
6. ★★★ **Инвентарь.** Команды приходят по одной в строке: `add предмет число` добавляет, `remove предмет число` убирает (в минус не уходим), `show` печатает пары «предмет число» по алфавиту или слово «пусто», `stop` завершает работу. *(по желанию)*

### Урок 4. Функции и модули

Файл: `lesson_4/4_Функции_и_модули.pptx`. Цель: делить программу на функции и файлы.

Темы: Зачем нужны функции; def и return; Пример: is_prime(n); Аргументы: позиционные, именованные, по умолчанию; *args и **kwargs; Несколько результатов сразу; Область видимости; Функции как объекты и lambda; Docstring и аннотации типов; Свои модули: два файла рядом; if __name__ == '__main__'; Стандартная библиотека; Игра «Угадай число».

Задачи:

1. ★ **Модуль helpers.py.** Создайте модуль `helpers.py` с функциями `is_palindrome(text)` (без учёта регистра) и `digits_sum(n)`. В файле `main.py` прочитайте строку и число, каждое на своей строке, и напечатайте два ответа, как в примере.
2. ★★ **«Угадай число» с попытками.** Программа загадывает число от 1 до 100 и даёт 7 попыток, подсказывая после каждой «загадано больше» или «загадано меньше». После партии спрашивает про новую игру: ответ `да` начинает её. Числа вводятся по одному в строке, последняя строка это ответ про повтор.
3. ★★ **Генератор паролей.** Функция `make_password(length=8, use_digits=True, use_specials=False)` возвращает случайный пароль. Прочитайте длину и напечатайте три пароля: по умолчанию, нужной длины и нужной длины со спецсимволами. Пароли каждый раз разные.
4. ★★ **Статистика списка.** Функция `stats(numbers)` возвращает кортеж: минимум, максимум, среднее и медиану. Медиана это середина отсортированного списка, а при чётной длине среднее двух середин. Первая строка ввода это количество чисел, дальше числа по одному в строке.
5. ★★★ **Калькулятор на словаре функций.** Соберите словарь `{'+': lambda a, b: a + b, ...}` для четырёх действий. Прочитайте первое число, знак операции и второе число, каждое на своей строке. Для неизвестного знака напечатайте `неизвестная операция`, для деления на ноль `на ноль делить нельзя`.
6. ★★★ **Рекурсия.** Функция вызывает саму себя, пока не дойдёт до простого случая. Напишите `factorial(n)` и `fib(n)` (первые два числа Фибоначчи равны 1) через рекурсию. Прочитайте `n` и напечатайте оба значения через пробел. Попробуйте `n = 35` и подумайте, почему так долго. *(по желанию)*

### Урок 6. ООП 1: классы и объекты

Файл: `lesson_6/6_ООП_1.pptx`. Цель: описывать сущности программы классами и раскладывать их по файлам.

Темы: Зачем ООП; class и объект; __init__ и self; Методы; __str__ и __repr__; Атрибуты класса и экземпляра; Инкапсуляция; Проблема: атрибут открыт всем; @property и setter; Что такое @; Классы по файлам; Скелет проекта: main.py.

Задачи:

1. ★ **Прямоугольник.** Класс `Rectangle(width, height)` с методами `area()`, `perimeter()` и с `__str__`. Ширина и высота это `@property` с проверкой: значение больше нуля, иначе `ValueError`. Программа читает ширину и высоту (каждое число на своей строке) и печатает три строки, а на неверном размере одну строку с ошибкой.
2. ★★ **Игрок.** Класс `Player(name)`: `score` равен нулю, попыток `MAX_ATTEMPTS = 6` (атрибут класса). Методы `lose_attempt()` (ниже нуля не опускается) и `add_score(points)`. `attempts_left` только для чтения через `@property`. Программа читает имя, число очков и число потерянных попыток (по одному значению на строке) и печатает игрока через `__str__`.
3. ★★ **Вопрос и мини-викторина.** Класс `Question(text, options, correct_index)`: `__str__` печатает вопрос и варианты с номерами от единицы, `check(index)` сверяет индекс (с нуля). Два вопроса подряд, ответ на своей строке, в конце счёт.
4. ★★ **Температура.** Класс `Temperature`: `celsius` это `@property` с проверкой (не ниже -273.15, иначе `ValueError`), `fahrenheit` считается из `celsius`, а его setter меняет `celsius`. Два числа, каждое на своей строке.
5. ★★★ **Викторина как проект.** Разложите викторину из задачи 3 по файлам: `models/question.py` (класс `Question`), `models/quiz.py` (класс `Quiz`: счёт и проверка ответов), `main.py` с `if __name__ == '__main__'`. Сами вопросы храните в файле `questions.json` и читайте их при старте. Это заготовка курсового проекта, только на маленькой теме. *(по желанию)*

## Курсовой проект

Консольная программа в ООП-стиле: Hangman, Wordle, Quiz или своя тема. Обязательный минимум:
не меньше трёх классов в папке `models/`, `main.py` с точкой входа, `__str__` в каждом классе,
инкапсуляция и `@property` с проверкой, обработка ошибок ввода, данные в файле, на выбор
наследование с полиморфизмом или внешняя библиотека. Полные требования, порядок защиты,
правила про ИИ и чеклист самопроверки: `course_project/Требования_к_курсовому_проекту.pdf`
(редактируемая версия в docx). Образец обязательной структуры: `course_project/example_project`.


## Карта папок

```
lesson_N/               презентация урока, demo/ (код со слайдов) и solutions/ (решения задач)
course_project/         требования к курсовому (docx и pdf) и образец структуры проекта
_build/                 генератор презентаций и документа, спецификация, план
_old/                   прежние материалы, перенесены без изменений
```

## Как пересобрать материалы

Презентации собираются из файлов `_build/content/lesson_N.py`. После правок:

```
cd _build
python3 build.py --all-checks      # собрать все уроки, исполнить примеры, прогнать demo и решения
python3 build.py 3 --render        # картинки слайдов урока 3 для просмотра
python3 docgen.py                  # документ требований (docx и pdf)
python3 syllabus.py                # этот файл
```

Нужны Python 3.10+, `python-pptx`, `python-docx`, `Pygments` и LibreOffice (для pdf и картинок).
Правки прямо в pptx тоже допустимы, но тогда при следующей пересборке они потеряются.
